Thông Tin API

                

                    

                        
GET /api/students

                        
Trả về danh sách 3 sinh viên mẫu với thông tin: ID, Tên, Lớp, Điểm.

                        

                            Response:
                            
{ "ok": 1, "msg": "Thành công", "students": [...] }

                        

                    

                    

                        
GET /api/rank?score=X

                        
Xếp loại điểm theo thang điểm 10:

                        
    
                            
  • ≥ 8.5: Giỏi
    • 
                            
  • ≥ 7.0: Khá
    • 
                            
  • ≥ 5.0: Trung bình
    • 
                            
  • < 5.0: Yếu
    • 
                        

                        
Validation: thiếu score, không phải số, < 0, > 10
